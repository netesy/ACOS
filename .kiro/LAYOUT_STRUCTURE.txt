CONSTRAINT FLOW (how sizing works):
─────────────────────────────────

Root receives: BoxConstraints(min_w=0, max_w=1280, min_h=0, max_h=800)
  │
  ├─ TopMenuBar receives: BoxConstraints(max_w=1280, max_h=752)
  │  └─ Returns: Size(1280, 48) ← fixed height
  │
  ├─ MainRow receives: BoxConstraints(max_w=1280, max_h=704)
  │  ├─ Sidebar receives: BoxConstraints(max_w=80, max_h=704)
  │  │  └─ Returns: Size(80, 704)
  │  │
  │  ├─ CenterContainer receives: BoxConstraints(max_w=1120, max_h=704)
  │  │  └─ Grid receives: BoxConstraints(max_w=1120, max_h=704)
  │  │     └─ Returns: Size(calculated, 704)
  │  │
  │  └─ Dashboard receives: BoxConstraints(max_w=300, max_h=704)
  │     └─ Returns: Size(300, 704)
  │
  └─ BottomDock receives: BoxConstraints(max_w=1280, max_h=44)
     └─ Returns: Size(1280, 44)

================================================================================

FIXED vs FLEXIBLE SIZING GUIDE:
───────────────────────────────

FIXED SIZING (use tight constraints):
  ✓ Top menu bar (always 48px)
  ✓ Bottom dock (always 56px)
  ✓ Sidebar width (always 80px)
  ✓ Dashboard width (always 300px)

FLEXIBLE SIZING (use loose constraints):
  ✓ Main row height (expand to fill)
  ✓ Desktop grid area (fill remaining width)
  ✓ All vertical spacing in columns
  ✓ Top menu content (expand horizontally)
